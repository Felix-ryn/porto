## 🎨 Visual Design

### Color Scheme
```
Primary Blue (Cerah):   #00B4D8  - CTAs, links, accents
Secondary Blue (Tua):   #0A4F7A  - Headers, navbar, dark areas
Accent (Highlight):     #00D4FF  - Hover effects, emphasis
Light Background:       #F0F7FF  - Page backgrounds
Text Dark:             #1A1A1A  - Main content
Text Light:            #666666  - Secondary content
```

- **Gradients** - Linear gradients untuk visual interest

- **Icons** - Emoji icons untuk visual appeal
- **Spacing** - Consistent padding/margin system

### Visual Effects
